# ぽかぽか もぐらたたき

30秒のもぐらたたき。タップ、クリック、数字キー1〜9で操作します。ハイスコアは、このブラウザのlocalStorageの既存キー `mogura_high` に保存します。個人情報・ログイン・外部API・外部ライブラリは不要です。

## アプリとして追加・オフライン

HTTPSの `/mogura-tataki/` 配下で配信します。対応ブラウザでは「アプリを ついか」から追加できます。ボタンが提供されない場合は「アプリの つかいかた」でブラウザのメニュー操作を確認できます。インストール可能性はブラウザ・端末・利用状況によります。

初回はオンラインで「オフラインの じゅんびが できたよ」が表示されるまで待ってください。必須ファイル8件をすべて保存できたことをService Workerに確認してから表示します。その後は同じブラウザでオフライン起動できます。ブラウザが保存領域を消去・退避した場合は再準備が必要です。

更新は待機させます。プレイ中の自動再読み込み、強制的なService Worker切り替えはありません。更新案内が出たら、ゲームの区切りでこのゲームのタブ・アプリをすべて閉じて、開き直してください。更新処理はハイスコアを変更しません。

## キャッシュの分離

- manifestの `id` / `start_url` / `scope`: `/mogura-tataki/`
- Service Worker: `/mogura-tataki/sw.js`
- 現行キャッシュ: `mogura-tataki-precache-v1`
- 旧版削除対象は `/^mogura-tataki-precache-v\d+$/` に一致する自アプリの名称だけです。
- 有効化の直前にも必須8件を再確認します。更新待機中に保存領域が失われた場合は、旧キャッシュを削除しません。
- 同一originかつ自身のscope内のGETだけを扱い、事前指定したアプリファイルだけをキャッシュから返します。
- リリース時はSWのキャッシュ版番号を必ず上げてください。待機中の新版と稼働中の旧版を別キャッシュに保持します。

3枚のPNGアイコンは、本リポジトリのオリジナル図形 `icons/mole.svg` から作成しました。192×192、512×512、maskable用512×512です。マスク用の背景は全面に描き、顔は中央のセーフゾーン内に配置しています。

## ローカル確認

アプリはビルド不要です。Node.js 24で、リポジトリ内から実行します。

```sh
node tests/server.mjs
# http://127.0.0.1:4197/mogura-tataki/
node --test tests/pwa.test.mjs
node --check pwa.js
node --check sw.js
```

ブラウザ回帰はインストール済みPlaywrightとEdgeを使用します。ゲーム側のnpm依存関係はありません。

```sh
node tests/browser.mjs
```

この作業環境では既存の `../../../manabi-sugoroku/node_modules/@playwright/test/index.mjs`（テストファイル基準）を読み取ります。別の配置では環境変数 `PLAYWRIGHT_MODULE` にPlaywrightのESMエントリーの `file:///.../index.mjs` を指定してください。`BROWSER_CHANNEL` の既定は `msedge` です。

Node回帰は8件で、待機中の資産消失時に旧キャッシュを残す処理も検証します。ブラウザ回帰対象：30秒実時間のキー操作、タッチ操作、390px表示、初回準備と失敗、オフライン再起動、最高点保持、旧版からの更新待機、全タブを閉じた後の有効化、他アプリのキャッシュ保持。ブラウザ試験のスクリーンショットはGit管理外の `artifacts/` に保存します。実機Chromebookでのインストールは別途確認が必要です。
